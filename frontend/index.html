Programmatic Integration

cURL Example 
curl -X POST https://your-domain.com/api/v1/predict \
  -H "Content-Type: application/json" \
  -H "X-API-Key: live_agyos_clinical_enterprise_key_99x" \
  -d '{
    "Age": 52,
    "Gender": "Male",
    "Condition": "Hypertension",
    "Drug_Name": "Amlodipine",
    "Dosage_mg": 250.0,
    "Treatment_Duration_days": 30
  }'
Python requests 
import requests

res = requests.post(
    "https://your-domain.com/api/v1/predict",
    headers={"X-API-Key": "live_agyos_clinical_enterprise_key_99x"},
    json={
        "Age": 52, "Gender": "Male",
        "Condition": "Hypertension",
        "Drug_Name": "Amlodipine",
        "Dosage_mg": 250.0,
        "Treatment_Duration_days": 30
    }
)
print(res.json()["predicted_score"])
